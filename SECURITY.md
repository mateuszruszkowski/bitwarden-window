# Security

Please use [private vulnerability reporting](https://github.com/mateuszruszkowski/bitwarden-window/security/advisories/new). If it is unavailable, contact the maintainer privately before sharing details. Include the affected commit, operating system, Bitwarden CLI version and expected behavior. Report using synthetic data only.

The window provides a limited command interface within one OS account. Software that can modify the user's shell, Bitwarden CLI, installed broker or configuration is outside this boundary. Keep your workstation and Bitwarden account protected. Rotating a compromised age identity also requires updating the recipients and recovery plan for affected backups.
